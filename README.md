# Quiet Strength

A gentle self-reflection and thrive toolkit for highly sensitive people (HSPs).

**Live app:** https://drgeid.github.io/Highly-Sensitive-People/

## What it does

- **The reflection** — 16 questions exploring the four facets of sensory processing sensitivity (depth of processing, ease of overstimulation, emotional responsiveness, sensing the subtle). Shows an overall score and the "shape" of each person's sensitivity.
- **Breathe** — guided cyclic sighing and 4-7-8 breathing with an animated pacer.
- **Ground** — an interactive 5-4-3-2-1 senses exercise.
- **Reset** — a checklist ritual for recovering after overstimulation.
- **Thrive** — practical strategies for each trait, opening on the person's leading trait.

The interface is intentionally low-stimulus: soft colours, slow motion, no sounds. Motion is reduced automatically for anyone who has "reduce motion" switched on.

## Privacy

Everything runs in the visitor's browser. No answers are stored, sent, or tracked.

## Running it

It is a single self-contained `index.html` — no installation or build step. Open it in any browser, or serve it with GitHub Pages.

## Acknowledgement

Inspired by Dr. Elaine Aron's research and her book *The Highly Sensitive Person* (1996). The questions are original and educational; this is not the validated HSP Scale and not a diagnosis. The official self-test is at [hsperson.com](https://hsperson.com).
